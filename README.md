# 블록체인 편 2장 「블록체인 기술」

연구실 해설 대시보드 시리즈의 블록체인 편 둘째 장입니다. 박사·하루(조수)·초파리 연구원·주판봇이 진행하는 인터랙티브 해설 페이지 7편과 목차로 이루어져 있습니다. 1장 「장부의 진화」가 "모두가 장부를 나눠 든다"에서 끝났다면, 2장은 그 장부의 부품(블록, 해시, 해시 사슬, 이력, 채굴, 난이도와 확정)을 하나씩 엽니다.

## 보는 법
- `index.html`을 브라우저로 열면 목차가 나옵니다. 설치나 서버가 필요 없습니다.
- GitHub Pages로 공개하려면 저장소 설정에서 Pages를 켜고 루트(`/`)를 고르면 됩니다.
- 외부 요청은 글꼴(Google Fonts) 하나뿐이고, 브라우저 저장소는 쓰지 않습니다.
- 페이지의 해시는 모두 브라우저에서 실제 SHA-256으로 계산합니다(외부 라이브러리 없음).
